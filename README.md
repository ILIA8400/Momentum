## ✨ چی داره؟

| بخش | امکانات |
|---|---|
| **داشبورد** | روزشمار کنکور، سلام بر اساس ساعت روز، جملهٔ انگیزشی، خلاصهٔ امروز با مقایسهٔ دیروز، نوار سهم درس‌ها، تایم‌لاین، انجام‌شده/مانده، یادداشت روز، زنجیرهٔ مطالعه |
| **ثبت مطالعه** | درس، ساعت شروع/پایان، خواندن / مرور / تست زدن، تعداد تست، درست/غلط با **درصد کنکوری (نمرهٔ منفی)** به‌صورت زنده، شرح، انجام‌شد |
| **روزانه / هفتگی / ماهانه** | نمای تقویمی شمسی (هفته از شنبه)، heatmap ماه، هدف کلی و به‌تفکیک درس با نوار پیشرفت |
| **آمار** | بازهٔ دلخواه، تفکیک درس، روند روزانه، درصد میانگین، **بهترین رکوردها** (بیشترین مطالعه/تست در روز، بهترین هفته، زنجیره) |
| **All Plan** | جدول «برنامه هفتگی انجام شده» (هفته × درس) مثل سایت کنکور کامپیوتر + گزارش تفصیلی هفته + جدول خلاصه — همه قابل چاپ/PDF |
| **ورود از اکسل** | قالب xlsx بگیر، برنامه‌های قبلی رو بریز، برگردون → اعتبارسنجی و پیش‌نمایش → تأیید → افزودن یک‌جا |
| **بکاپ** | بکاپ خودکار SQLite (هر اجرا، هر ۶ ساعت، هنگام خروج)، بکاپ کامل JSON، خروجی CSV، بازیابی، پاک کردن تاریخچه با دو مرحله تأیید |
| **تم** | روشن / تاریک / خودکار |

## 🚀 نصب و اجرا

**پیش‌نیاز:** فقط [Node.js](https://nodejs.org) نسخهٔ LTS (۲۲ به بالا).

1. این ریپو رو دانلود کن (Code → Download ZIP) و باز کن.
2. روی **`install.bat`** دابل‌کلیک کن → میان‌بر ⚡ Momentum روی دسکتاپ ساخته می‌شه.
3. از میان‌بر اجرا کن → در پس‌زمینه بالا میاد و مرورگر روی `http://localhost:3000` باز می‌شه.

| فایل | کار |
|---|---|
| `install.bat` | نصب یک‌باره: چک Node، میان‌بر دسکتاپ، اجرای خودکار با ویندوز (اختیاری) |
| میان‌بر دسکتاپ / `start-hidden.vbs` | اجرا در پس‌زمینه بدون پنجرهٔ سیاه |
| `start.bat` | اجرا با پنجرهٔ کنسول (برای دیدن لاگ) |
| `stop.bat` | خاموش کردن دستی (داخل اپ هم: تنظیمات → «خاموش کردن Momentum») |

- تب مرورگر رو ببندی، اپ خودش خاموش می‌شه و پورت آزاد می‌شه؛ چیزی در پس‌زمینه نمی‌مونه.
- دو بار اجرا کنی نمونهٔ دوم ساخته نمی‌شه؛ فقط مرورگر باز می‌شه.
- پورت ۳۰۰۰ اشغال باشه، خودش پورت بعدی رو برمی‌داره.
- `npm start` / `npm stop` هم کار می‌کنه. `npm install` لازم نیست.

راهنمای کامل کاربر (نصب، استفاده، بکاپ، اشتراک‌گذاری با دوستان، رفع مشکل): **[GUIDE.md](GUIDE.md)** — داخل اپ هم با دکمهٔ «؟» باز می‌شه.

## 💾 داده‌ها کجاست؟

- دیتابیس: `data/plan.db` (SQLite، یک فایل).
- بکاپ‌های خودکار: `backups/` (۳۰ فایل آخر).
- این دو پوشه در `.gitignore` هستن؛ دیتای شخصی هیچ‌وقت وارد ریپو نمی‌شه.
- توصیه: هفته‌ای یک بار از داشبورد «بکاپ کامل» (JSON) بگیر و جای امن بذار — این فایل همه‌چیز از روز اول رو داره و با «بازیابی از JSON» برمی‌گرده.

## 🧱 ساختار پروژه

```
server.js            HTTP سرور + API (بدون فریمورک)
src/db.js            لایهٔ داده (node:sqlite)، migration، آمار، رکوردها
src/jalali.js        تبدیل تاریخ شمسی/میلادی
src/backup.js        بکاپ خودکار (VACUUM INTO)
src/xlsx.js          خواندن/نوشتن xlsx بدون وابستگی (zip + XML)
src/importer.js      قالب اکسل، اعتبارسنجی و پیش‌نمایش ورود
public/              رابط کاربری (HTML/CSS/JS ساده، بدون build)
  ├─ app.js          تب‌ها: داشبورد، روزانه، هفتگی، ماهانه، آمار، ورود از اکسل، تنظیمات
  ├─ allplan.html    جدول All Plan (هفته × درس)
  ├─ report.html     گزارش تفصیلی هفته
  ├─ summary.html    جدول خلاصهٔ هفته
  └─ guide.html      راهنمای داخل اپ
test/                تست‌ها (node:test)
tools/make-icon.js   ساخت آیکون
```

ریپو رو بهشون بده یا پوشه رو **بدون** `data/` و `backups/` زیپ کن. هر کس Node نصب می‌کنه، `install.bat` رو می‌زنه و دیتای خودش رو داره.
