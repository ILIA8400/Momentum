# ⚡ Momentum — برنامه‌ریز مطالعه

ساخته شده توسط سینیور ایلیا.

اپ لوکال و آفلاین برنامه‌ریزی درسی با تقویم شمسی، روزشمار کنکور، ثبت مطالعه/تست/درصد، هدف‌گذاری، آمار، گزارش هفتگی All Plan و ورود از اکسل. بدون هیچ وابستگی خارجی — فقط Node.js (نسخهٔ ۲۲ به بالا). راهنمای کامل: [GUIDE.md](GUIDE.md) یا داخل اپ (دکمهٔ «؟»).

## نصب (یک بار)

1. [Node.js](https://nodejs.org) نسخهٔ LTS را نصب کن.
2. روی **`install.bat`** دابل‌کلیک کن → میان‌بر «Momentum» روی دسکتاپ ساخته می‌شود (و در صورت تمایل، اجرای خودکار با ویندوز).

## اجرا

| روش | چی می‌شود |
|---|---|
| میان‌بر **Momentum** روی دسکتاپ (یا `start-hidden.vbs`) | در پس‌زمینه بدون پنجرهٔ سیاه اجرا می‌شود و مرورگر باز می‌شود |
| `start.bat` | با پنجرهٔ کنسول (لاگ‌ها را می‌بینی) + مرورگر باز می‌شود |
| `npm start` | همان `start.bat` |
| `stop.bat` یا تنظیمات → «خاموش کردن Momentum» | سرور را خاموش می‌کند (با بکاپ) |

- اگر Momentum از قبل باز باشد، اجرای دوباره فقط مرورگر را باز می‌کند (نمونهٔ دوم ساخته نمی‌شود).
- اگر پورت ۳۰۰۰ را برنامهٔ دیگری گرفته باشد، خودش پورت بعدی (۳۰۰۱، ۳۰۰۲…) را برمی‌دارد و مرورگر را روی همان باز می‌کند. پورت فعلی در `data/port.txt` است.
- خاموش که می‌شود پورت آزاد می‌شود؛ چیزی در پس‌زمینه نمی‌ماند.

## داده‌ها و بکاپ

- دیتابیس: `data/plan.db` (SQLite). بکاپ خودکار در `backups/`: هر اجرا، هر ۶ ساعت، هنگام خروج، قبل از بازیابی/ورود از اکسل/پاک کردن تاریخچه (۳۰ فایل آخر).
- بکاپ کامل JSON (همه‌چیز از روز اول) و خروجی CSV از داشبورد/تنظیمات. بازیابی از JSON در تنظیمات.
- بازگرداندن `.db`: سرور را خاموش کن، فایل بکاپ را به `data/plan.db` کپی کن و `plan.db-wal`/`plan.db-shm` را پاک کن.

## گزارش‌ها

- **All Plan**: جدول «برنامه هفتگی انجام شده» (هفته × درس) — `/allplan.html`
- گزارش تفصیلی هفته — `/report.html` · جدول خلاصهٔ هفته — `/summary.html`
- همه قابل چاپ/ذخیره به PDF هستند.

## ورود از اکسل

تب «ورود از اکسل»: قالب `momentum-template.xlsx` را بگیر، پر کن، برگردان → پیش‌نمایش و اعتبارسنجی → تأیید → افزودن یک‌جا.
